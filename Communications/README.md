# Communications

![SoutheastCon Communications](../images/SoutheastCon_Communications.png)

The **Communications** tutorials introduce the techniques used to exchange information between the Arduino Mega 2560, ESP32, and other systems in the SoutheastCon Circuit Design Challenge.

The tutorials will progress from simple, easy-to-understand connections to more capable and reliable communication systems. Each tutorial is intended to build on the skills developed in the previous one.

## Planned Topics

- **Direct Serial Communication** — Establish a basic UART connection between the Arduino Mega 2560 and ESP32.
- **Infrared Communication** — Replace the wired connection with a short-range infrared link.
- **Modulated Infrared Communication** — Use a modulated infrared carrier and a demodulating receiver for improved reliability.
- **Bidirectional Communication** — Develop two-way communication between the Arduino and ESP32.
- **CRC Error Detection** — Add CRC-16 error detection to transmitted data.
- **ACK/NACK and Retransmission** — Detect failed packets, acknowledge successful packets, and retransmit data when necessary.
- **Telemetry** — Build toward the communications used to send competition data to the ground station.

The emphasis throughout these tutorials is on understanding how the communication system works, testing each stage independently, and then combining the techniques into a reliable system.
